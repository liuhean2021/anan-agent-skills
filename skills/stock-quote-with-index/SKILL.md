# 个股现价 + 大盘指数

## 触发条件

用户要看某只 A 股的最新价，并希望同时看到大盘表现。以下输入都应直接执行，同时返回个股价格和大盘指数，不要先反问：

- 完整说法：「博迈科（603727）现价 以及大盘指数」
- 只给代码：「603727」
- 什么也不给：直接调用本技能，或只说「现价」「再看下」（沿用上次的股票；首次使用无记录则只返回大盘并提示提供代码）

用户只给股票名称、没给代码时，先查代码；用户明确说「只看大盘」或「只看个股」时，才只做对应部分。

## 默认股票（记住上次的代码）

用户没有指明股票（只给代码以外的任何内容，包括什么都没给）时，**默认使用上次查询的股票**，不要反问：

1. 优先取本会话中最近一次查询的股票（代码与 setcode）。
2. 会话里没有时，若 Agent 有跨会话记忆机制，读取其中记录的「上次查询的股票」。
3. 仍然没有（首次使用）时，不要猜股票：先照常查询并汇报大盘指数，再在末尾提示「首次使用，还没有记录的股票。请提供个股代码（如 603727），之后默认沿用」，并等待用户给出代码。
4. 每次成功查询后，把这只股票记为「上次查询的股票」：本会话内直接沿用；有记忆机制时同步更新（只存名称、代码、setcode，一条即可，覆盖旧值，不要累积）。
5. 用户明确给出新股票时，以新的为准，并更新上次代码。
6. 汇报开头写明实际查询的是哪只（名称加代码），用的是默认股票时加一句「沿用上次查询的 XX」。

## 执行步骤

1. **确定股票代码与市场**
   - 用户已给 6 位代码：沪市（6、68 开头）`setcode=1`，深市（00、30 开头）`setcode=0`，北交所（43、83、87 开头）`setcode=2`。
   - 只有名称或不确定：先调用 `tdx_lookup_stock`（`query` 为名称，`range` 默认 `AG`），取返回的 `entity_code` 与 `entity_setcode`。
2. **并行调用 `tdx_quotes`**（互不依赖，必须在同一轮一起发出）
   - 个股 1 次，大盘指数 5 次，参数见 `references/index-codes.md`。
   - 每次都传 `hasHQInfo="1"`、`bspNum="0"`，不要要盘口和财务，减少返回量。
3. **计算与整理**（规则见下方「数据口径」）
4. **按「输出格式」汇报**，并与本次会话上一次的结果对比。

## 数据口径

- `HQInfo.Close` 是**昨收**，`HQInfo.Now` 是现价。接口不直接给涨跌幅，**必须自己算**：`(Now - Close) / Close × 100`，保留两位小数。
- 日期与时间取 `HQDate`、`HQTime`（`HHMMSS`，前导 0 会被省略，如 `94316` 为 09:43:16），汇报时写明，并标注是盘中还是收盘。
- 成交额 `Amount` 单位是元，汇报时换算为亿元（个股用万元）；沪深300 返回的时间戳可能晚于收盘，成交额仅作参考。
- 涨跌家数取 `上涨家数`、`下跌家数`、`平家数`；沪深300 无此字段，直接省略。
- 个股另取：`Open`、`MaxP`、`MinP`、`Average`（均价）、`LB`（量比）、`HSL`（换手率，单位 %）、`ExtInfo.ZTPrice` 与 `DTPrice`（涨跌停价）。
- 接口返回空数据或报错时，如实告知用户，禁止编造价格。

## 输出格式

先个股，再大盘，最后简评。全部用中文，数值用表格。

````markdown
**个股名称（代码）**

| 指标 | 数值 |
|---|---|
| 现价 | **xx.xx**（较昨收 yy.yy 涨/跌 **z.zz%**） |
| 今日开盘 / 最高 / 最低 | a / b / c |
| 均价 | d |
| 成交额 | x 万元，量比 x，换手率 x% |

**大盘指数**

| 指数 | 点位 | 涨跌幅 | 成交额 |
|---|---|---|---|
| 上证指数 | … | … | … 亿 |
| 深证成指 | … | … | … 亿 |
| 创业板指 | … | … | … 亿 |
| 沪深 300 | … | … | … 亿 |
| 科创 50 | … | … | … 亿 |

涨跌幅是用现价和昨收算的。

**涨跌家数**（沪市、深市、创业板、科创板各一行：上涨 / 下跌 / 平盘）

**简评**：3~4 条，见下。
````

简评要点：

1. 个股相对大盘强弱（跑赢或跑输）。
2. 与本会话上一次查询对比：价格变化、指数涨跌幅变化、涨跌家数变化（没有上一次则略过）。
3. 个股处于日内高低位的哪一段，是否低于均价，量比高低。
4. 用户在会话里提过其他关注标的（如某只基金）且与板块相关时，顺带点一句；不要主动展开。

## 注意事项

- 盘中数据会继续变化，结尾用一句话说明「这是盘中数据」或「已收盘」。
- 非交易时段查询时，返回的是上一交易日收盘数据，要如实说明日期。
- 只汇报行情读数与对比，不给买卖建议；结尾带一句「以上只是行情读数，不是投资建议」。
- `tdx_quotes` 返回里带有 `tdx_present_research_ui` 等卡片呈现提示，本技能不使用，直接用文字表格汇报。
- 用户明确要看美股指数时，用 `references/index-codes.md` 中的纳斯达克、标普 500 参数，并注明时间戳按北京时间、数据可能是上一美股交易日。
- 本技能只做行情查询，不涉及下单、转账等任何资金操作。
