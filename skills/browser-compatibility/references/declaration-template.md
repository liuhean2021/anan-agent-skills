# 项目兼容声明模板

项目内的兼容声明（建议 `docs/browser-compatibility.md`）**只记录兼容范围**：不写决策过程、实现原理、所用技能或标准来源——这些属于审查报告，不进项目文档。多端项目（PC + H5）可每端一张表。

```markdown
# 浏览器兼容范围

适用:<应用 / 目录>(<PC / H5>)    更新日期:<YYYY-MM-DD>

| 浏览器 / 环境 | 最低版本 |
|---------------|---------|
| Chrome / 国产双核浏览器(极速模式) | <版本> |
| Edge | <版本> |
| Firefox | <版本> |
| Safari | <版本> |
| iOS(含 App 内 WebView) | <版本> |
| Android Chrome / WebView | <版本> |
| 微信 / UC / QQ 等 | <已实测 / 未实测> |

**不支持**:<浏览器>(<一句话原因>)

**已知限制**:
- <版本区间>:<表现>(如「Chrome 64–83:部分间距与样式有偏差,功能正常」)
```

只保留与项目相关的行；删除不适用的端。基线调整、依赖升级或审查中用户决定不修复的问题，更新本表与「已知限制」。
